Recommended production workflow

  1. Run node server.js.
  2. Open the control panel on the laptop.
  3. Use /overlay.html as a 1920×1080 OBS Browser Source.
  4. Use OBS Video Capture Device for the camera, or the included browser camera when needed.
  5. Start OBS Virtual Camera and select it in Zoom.

Phone / tablet remote

On the same network open http://YOUR-PC-IP:8080/remote.html. The local server synchronizes control, remote and OBS in real time without a paid cloud service.

Portable configuration

Export all branding, timer, workout and layout settings to JSON and import them on another machine/server.
